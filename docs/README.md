# OctoAcme Project Management Docs

This repository contains the core project management process documents for OctoAcme. These docs provide a consistent way to initiate, plan, execute, release, and improve work across projects.

## Project management process summary
OctoAcme uses a lightweight, iterative project management model built around clear roles, stakeholder alignment, milestone planning, risk tracking, and continuous improvement. Work typically begins with project initiation and a one-pager, moves into prioritized planning and backlog definition, then continues through execution with standups, tracking, and issue escalation. The team validates quality throughout delivery, releases with defined checks and rollback plans, and closes the cycle with retrospectives to capture lessons and improve future work.

## Purpose
These documents help teams align on roles, responsibilities, communication practices, delivery workflows, and quality expectations so work can be executed consistently and with less risk.

## Typical lifecycle
1. Initiation: define the problem, stakeholders, success criteria, and early risks.
2. Planning: create the backlog, estimate scope, define milestones, and identify dependencies.
3. Execution: build incrementally, track progress, escalate blockers, and keep stakeholders informed.
4. Release: validate readiness, deploy, communicate outcomes, and verify impact.
5. Retrospective: review what worked, identify improvements, and track follow-up actions.

## How to use this folder
Use the overview and role docs for context, the initiation and planning docs to start a project, and the execution, risk, release, and retrospective docs to manage delivery and improvement over time.
